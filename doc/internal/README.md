# Internal Documentation

This directory contains internal design documents and maintainer guides that are not intended for end users.

- **[publishing.md](publishing.md)** - Guide for publishing Kodama to Maven Central (maintainers only)
- **[subquery-design.md](subquery-design.md)** - Design document for subquery support implementation

- How to publish releases
- The evolution of the API design
